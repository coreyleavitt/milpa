  **epoch** is the only guard against a *breaking semantic redefinition of existing syntax* (old
  impl parses new manifest & silently misinterprets) — the cardinal sin for a multi-impl,

  naive lockfile hard-gate):** `spec-version <int>` epoch, **optional, absent ⇒ 1**; bumped ONLY
  for breaking semantic changes; additive evolution stays within an epoch (P3 handles it, no bump);
  unsupported epoch (value > MANIFEST_SPEC_VERSION=1) → precise `MAN-SPEC-VERSION-UNSUPPORTED`.
  This reuses the RFC's own G4 major-vs-minor bump discipline. Absent stays absent on emit
